cherrypick

cherry pick was one of the git command which helps to add the purticular commit to the current branch

1. push the current code in main branch

2. create a new branch and switch to that branch

3. make some changes and commit the code into the created branch

4. create a another new branch and exit and push the code into that branch

5. switch to the first branch and use the command git cherry-pick to add the commit into the first branch
